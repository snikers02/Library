# Library Project (Lab 5)
![CI Pipeline](https://github.com/snikers02/Library/actions/workflows/ci.yml/badge.svg)

## Мета
Проєкт демонструє реалізацію базової бізнес-логіки бібліотеки з архітектурою **Controller–Service–Repository** та покриттям юніт-тестами.

## Реалізовані бізнес-сценарії
- **Реєстрація користувача**: створення нового читача за ім’ям та email.
- **Позичання (видача) книги**: видача книги користувачу з перевірками:
  - книга існує;
  - користувач існує;
  - книга доступна (`available`);
  - не перевищено ліміт книг на користувача.
- **Повернення книги**: повернення книги в бібліотеку та оновлення станів.
- **Пошук книг**: пошук за назвою або автором (по підрядку, case-insensitive).

## Структура проєкту
Вихідний код розміщено в `src/` та розділено на шари:

- `src/controllers/` — контролери (вхідна точка, без бізнес-логіки)
- `src/services/` — сервіси (вся бізнес-логіка)
- `src/repositories/` — репозиторії (доступ до даних; у лабораторній використано in-memory реалізацію)
- `src/models/` — моделі (сутності `Book`, `User`)
- `src/dto/` — DTO для вхідних даних
- `tests/` — юніт-тести (pytest)

## Встановлення залежностей
Перейдіть у корінь `library_project` та встановіть залежності:

```bash
python -m pip install -r requirements.txt
```

## Запуск юніт-тестів
Запуск тестів виконується з кореня `library_project`:

```bash
python -m pytest -q
```

### Приклад “журналу” (виводу) запуску тестів
Очікуваний приклад результату:

```text
..........                                                               [100%]
10 passed in 0.07s
```

## Пояснення логіки тестів
Тести зосереджені на сервісному шарі `LibraryService` і включають позитивні та негативні сценарії:
- успішна реєстрація користувача;
- дублювання email при реєстрації;
- успішна видача книги;
- спроба видачі книги, якщо:
  - користувача не існує;
  - книги не існує;
  - книга вже позичена;
  - перевищено ліміт книг;
- успішне повернення книги;
- повернення книги, яка вже доступна;
- пошук книг за назвою/автором.

## Додатково (перевірка стилю)
